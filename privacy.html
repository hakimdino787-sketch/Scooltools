الخصوصية

سياسة الخصوصية

توضيح مبسط لكيفية تعامل الأدوات المختلفة مع البيانات.

الأدوات المحلية

بعض الأدوات في Scooltools تعمل داخل المتصفح مباشرة، مثل بعض عمليات الحساب ومعالجة النصوص والصور. في هذه الحالات قد لا يحتاج الملف إلى الرفع للخادم حتى تنفذ المهمة.

خدمات API والذكاء الاصطناعي

الأدوات التي ترسل طلبات إلى API قد تنقل النص الذي أدخلته إلى الخادم لتنفيذ المهمة. لا تضع معلومات سرية أو كلمات مرور أو مفاتيح API في هذه الأدوات.

الخدمات الخارجية

بعض الوظائف تستخدم خدمات خارجية، مثل إنشاء رمز QR أو روابط مصادر محتوى. عند استعمال خدمة خارجية، تنطبق أيضاً سياسة الخصوصية وشروط تلك الخدمة.

الملفات

قبل اختيار ملف داخل أي أداة، اقرأ وصف الأداة لمعرفة هل تتم المعالجة محلياً أم عبر خدمة خارجية. لا ترفع ملفات حساسة إلى خدمة لا تثق بها.

التحديثات

قد تتغير طريقة عمل الأدوات مع إضافة ميزات أو مزودين جدد. عند تغيير جوهري في معالجة البيانات ينبغي تحديث هذه الصفحة.

تنبيه: هذه صفحة معلومات عامة وليست استشارة قانونية، ويجب مراجعة الإعدادات والسياسات الفعلية للخدمات الخارجية المستخدمة.
